# Threads Downloader

[English](README.md) | [繁體中文](README.zh-TW.md) | **简体中文**

[立即打开 Threads Downloader 正式服务](https://threads.pylot.dev/)

Threads Downloader 是一款独立工具，可帮助你下载“无需登录即可观看”的公开 Threads 帖子视频。
本服务并非 Threads 官方服务，也未获得 Threads、Meta 或 Instagram 的背书。

## 使用方法

1. 打开[正式服务](https://threads.pylot.dev/)。
2. 粘贴公开 Threads 帖子的网址。
3. 确认你拥有该内容，或已取得下载并使用该内容的权利。
4. 选择“获取视频”；安全验证通常会自动完成，无需额外操作。
5. 选择需要的视频版本并下载。

## 支持范围

- 仅支持普通访客无需登录即可观看的公开 Threads 帖子。
- 不处理私人、仅限登录、有年龄限制、有地区限制或其他受限内容，也不会绕过访问限制。
- Threads 页面格式或平台限制可能发生变化，因此无法保证每个公开帖子都能成功解析。
- 请仅下载你有权使用的内容；公开可见并不意味着可以任意使用。

完整的使用条款、隐私与数据处理说明，以及著作权与下架通知不会直接铺在首页。请在网站页眉或页脚选择
对应链接，相关内容会在窗口中显示。如有著作权、下架或隐私相关问题，可发送电子邮件至
[pony@pylot.dev](mailto:pony@pylot.dev)。

## 遇到问题

- 显示“请先完成安全验证。”：稍等几秒后重试，并确认浏览器没有阻止网站所需的脚本。
- 无法解析：确认网址来自公开帖子，且无需登录；稍后重试仍然失败时，该帖子可能不在支持范围内。
- 无法下载：重新解析并选择视频版本；下载链接会在一段时间后失效。
- 问题持续发生：请前往[项目源代码仓库](https://github.com/Willseed/ThreadsDownloader)反馈，
  并描述界面上显示的错误信息；请勿公开发布私人内容或账号信息。
