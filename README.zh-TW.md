# Threads Downloader

[English](README.md) | **繁體中文** | [简体中文](README.zh-CN.md) | [Español](README.es.md) | [한국어](README.ko.md)

[立即開啟 Threads Downloader 正式服務](https://threads.pylot.dev/)

Threads Downloader 是協助你下載「免登入即可觀看」的公開 Threads 貼文影片的獨立工具。
本服務不是 Threads 官方服務，也沒有獲得 Threads、Meta 或 Instagram 的背書。

## 使用方式

1. 開啟[正式服務](https://threads.pylot.dev/)。
2. 貼上公開的 Threads 貼文網址。
3. 確認你擁有內容，或已取得下載與使用內容的權利。
4. 按下「取得影片」；安全驗證通常會自動完成，不需要多做一次操作。
5. 選擇需要的影片版本並下載。

## 支援範圍

- 僅支援不必登入就能由一般訪客觀看的公開 Threads 貼文。
- 不處理私人、登入限定、年齡限制、地區限制或其他受限內容，也不會繞過存取限制。
- Threads 頁面格式或平台限制可能改變，因此無法保證每一則公開貼文都能成功解析。
- 請只下載你有權使用的內容；公開可見不代表可以任意使用。

完整的使用條款、隱私與資料處理說明，以及著作權與下架通知不會直接鋪在首頁。請在網站頁首或頁尾點選
對應連結，內容會在視窗中顯示。著作權、下架或隱私相關問題可寄至
[pony@pylot.dev](mailto:pony@pylot.dev)。

## 遇到問題

- 顯示「請先完成安全驗證。」：稍候幾秒再試，並確認瀏覽器沒有阻擋必要的網站腳本。
- 無法解析：確認網址來自公開貼文，且不需要登入；稍後再試仍失敗時，該貼文可能不在支援範圍。
- 無法下載：重新解析並選擇影片版本；下載連結會在一段時間後失效。
- 問題持續發生：請到[專案原始碼倉庫](https://github.com/Willseed/ThreadsDownloader)回報，
  並描述畫面上的錯誤訊息；請勿公開貼出私人內容或帳號資料。
