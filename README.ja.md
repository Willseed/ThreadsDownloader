# Threads Downloader

[English](README.md) | [繁體中文](README.zh-TW.md) | [简体中文](README.zh-CN.md) | [Español](README.es.md) | [한국어](README.ko.md) | **日本語**

[Threads Downloaderを開く](https://threads.pylot.dev/)

Threads Downloaderは、一般の利用者がログインせずに閲覧できる公開Threads投稿の動画をダウンロードする
ための独立したツールです。Threadsの公式サービスではなく、Threads、Meta、Instagramによる
推奨や承認を受けていません。

## 使い方

1. [ライブサービス](https://threads.pylot.dev/)を開きます。
2. 公開Threads投稿のURLを貼り付けます。
3. コンテンツを所有しているか、許可を得ているか、適用法に基づいて予定する利用が認められて
   いることを確認します。
4. **動画を取得**を選択します。セキュリティ確認が表示された場合は、画面の案内に従って
   完了してください。
5. 必要な動画のバージョンを選択し、画面の案内に従って開くか保存します。

## 対応コンテンツ

- 一般の閲覧者がログインせずに表示できる公開Threads投稿のみが対象です。
- 非公開、ログイン必須、年齢制限、地域制限、その他の制限付きコンテンツは処理せず、アクセス
  制限も回避しません。
- Threadsのページ形式やプラットフォームの制限は変更される可能性があるため、すべての公開
  投稿を正常に解析できることは保証されません。
- 利用する権利があるコンテンツだけをダウンロードしてください。一般公開されていることは、
  制限なく利用する許可を与えるものではありません。

利用規約、プライバシーおよびデータ処理に関する通知、著作権および削除要請に関する通知の全文は、
サイトのヘッダーまたはフッターから開くことができ、ダイアログに表示されます。著作権、削除要請、
プライバシーに関するお問い合わせは、[pony@pylot.dev](mailto:pony@pylot.dev)までお送りください。

## トラブルシューティング

- **まずセキュリティ確認を完了してください。** 数秒待ってからもう一度試し、ブラウザがサイトに
  必要なスクリプトをブロックしていないことを確認してください。
- **投稿を解析できません。** URLがログイン不要の公開投稿を指していることを確認してください。
  時間を置いても失敗する場合は、その投稿が対応範囲外である可能性があります。
- **動画をダウンロードできません。** 投稿をもう一度解析してバージョンを選択してください。
  ダウンロードリンクは一定時間後に期限切れになります。
- **問題が解決しません。** [プロジェクトリポジトリ](https://github.com/Willseed/ThreadsDownloader)で、
  画面に表示されたエラーメッセージを添えて報告してください。公開Issueには、非公開コンテンツや
  アカウント情報を投稿しないでください。
