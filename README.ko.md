# Threads Downloader

[English](README.md) | [繁體中文](README.zh-TW.md) | [简体中文](README.zh-CN.md) | [Español](README.es.md) | **한국어**

[Threads Downloader 라이브 서비스 열기](https://threads.pylot.dev/)

Threads Downloader는 로그인하지 않고도 누구나 볼 수 있는 공개 Threads 게시물의 동영상을
다운로드하는 독립 도구입니다. Threads 공식 서비스가 아니며 Threads, Meta 또는 Instagram의
보증을 받지 않았습니다.

## 사용 방법

1. [라이브 서비스](https://threads.pylot.dev/)를 여세요.
2. 공개 Threads 게시물의 URL을 붙여넣으세요.
3. 콘텐츠 소유자이거나 허가를 받았거나 관련 법률에 따라 의도한 방식으로 이용할 수 있는지
   확인하세요.
4. **동영상 가져오기**를 선택하세요. 보안 인증은 일반적으로 자동으로 실행되지만 추가 작업이
   필요한 경우 화면의 안내를 따르세요.
5. 필요한 동영상 버전을 선택하여 다운로드하세요.

## 지원되는 콘텐츠

- 일반 방문자가 로그인 없이 볼 수 있는 공개 Threads 게시물만 지원됩니다.
- 비공개 콘텐츠, 로그인이 필요한 콘텐츠, 연령 또는 지역이 제한된 콘텐츠와 그 밖의 제한된
  콘텐츠는 처리하지 않으며 접근 제한을 우회하지 않습니다.
- Threads 페이지 형식과 플랫폼 제한은 변경될 수 있으므로 모든 공개 게시물을 분석할 수 있다고
  보장하지 않습니다.
- 사용할 권리가 있는 콘텐츠만 다운로드하세요. 공개적으로 볼 수 있다는 사실이나 연구 또는
  비상업적 목적만으로 다운로드하거나 이용할 권한이 부여되거나 해당 이용의 적법성이 보장되는
  것은 아닙니다.

전체 이용 약관, 개인정보 보호 및 데이터 처리 안내, 저작권 및 삭제 요청 안내는 사이트 헤더 또는
바닥글에서 열 수 있으며 대화 상자로 표시됩니다. 저작권, 삭제 요청 또는 개인정보 보호 관련 문의는
[pony@pylot.dev](mailto:pony@pylot.dev)로 보내세요.

## 문제 해결

- **먼저 보안 인증을 완료하세요.** 몇 초 기다린 후 다시 시도하고 브라우저가 사이트에 필요한
  스크립트를 차단하지 않는지 확인하세요.
- **게시물을 분석할 수 없습니다.** URL이 로그인하지 않고 볼 수 있는 공개 게시물인지 확인하세요.
  나중에도 계속 실패하면 지원 범위에 포함되지 않는 게시물일 수 있습니다.
- **동영상을 다운로드할 수 없습니다.** 게시물을 다시 분석하고 버전을 선택하세요. 다운로드 링크는
  일정 시간이 지나면 만료됩니다.
- **문제가 계속됩니다.** [프로젝트 저장소](https://github.com/Willseed/ThreadsDownloader)에 화면에
  표시된 오류 메시지와 함께 신고하세요. 공개 이슈에 개인정보, 비공개 콘텐츠 또는 계정 정보를
  게시하지 마세요.
